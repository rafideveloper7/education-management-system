## 📝 2. Homework Tasks (`assignments`)

Created by teachers for their assigned classes and subjects.

### Real-World Assignment Example:
```
Title:            Newton's Laws of Motion - Numerical Set 2
Class & Subject:  Class 10-A | Physics
Teacher:          Prof. Sarah Ahmed
Assigned Date:    01 September 2026
Due Deadline:     05 September 2026 (Friday 11:59 PM)
Total Marks:      20 Marks (Pass: 10 Marks)
Attached Files:   Problems_Sheet_Ch3.pdf
```

| Field Name | What is it? | Example Value | Description |
|---|---|---|---|
| **`title`** | Homework Title | `"Newton's Laws Problem Set"` | What the assignment is called |
| **`description`** | Instructions | `"Solve all problems on page 42"` | Clear task instructions |
| **`dueDate`** | Due Deadline | `"2026-09-05"` | When students must submit work by |
| **`totalMarks`** | Max Score | `20` | Full marks for this task |
| **`attachments`** | Attached Files | `["Problems.pdf"]` | Reference worksheets or PDF files |

## 📤 3. Student Submissions (`submissions`)

Uploaded by students and evaluated by teachers.

### Real-World Student Submission:
```
Student Name:     Ali Khan (Class 10-A)
Uploaded At:      04 September 2026 at 06:30 PM
Uploaded File:    Ali_Khan_Physics_HW.pdf
Marks Obtained:   18 / 20 Marks
Teacher Feedback: "Very neat presentation and accurate calculations!"
Status:           GRADED
```

---

## 💡 Summary: Why this design makes decision-making easy

1. **Deadlines & Overdue Alerts**: Parents can check which homework tasks are due this week so students never fall behind.
2. **Clear Feedback Loops**: If a student makes a mistake, the teacher can ask for a revision instead of just giving zero marks.
3. **Paperless Submissions**: All homework files and scores are securely stored online for future term assessments.
