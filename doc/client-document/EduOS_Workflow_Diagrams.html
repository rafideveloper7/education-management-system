Phase 1: Creation

Teacher creates coursework with attachments, instructions, maximum score, and clear deadlines.

Phase 2: Alert

Both student and parent receive instant notifications; task appears in student pending queue.

Phase 3: Submission

Student uploads solution file online; timestamp is recorded to monitor punctuality.

Phase 4: Feedback

Teacher grades submissions with marks and remarks; grades reflect live in parent portal.
