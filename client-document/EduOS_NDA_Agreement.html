2 Project Description

The Parties agree to collaborate on the following project ("the Project"):

Party A agrees to design, develop, and deliver a complete Education Management System (hereinafter referred to as "EduOS") — a full-stack, web-based digital platform for educational institutions. The system shall include the following components:

  1. Public Website — A fully dynamic, Admin-controlled public-facing website including: Homepage, About, Programs, Faculty, Admissions, Events, Notices, Gallery, Contact, and all supporting pages.
  2. Authentication System — A single unified login that identifies user role and routes to the correct panel (Admin, Teacher, Student, Parent, or Public User).
  3. Admin Panel — Complete institutional control including student, teacher and parent management; academic structure; timetable; attendance supervision; exam and result management; fee management; admission processing; ID card generation; notice system; reporting; website management; and system settings.
  4. Teacher Panel — Tools for managing assigned classes; taking attendance; creating and grading assignments; entering exam marks; viewing timetable; and submitting applications.
  5. Student Panel — Personal academic workspace including attendance, assignments, exams, results, fee status, applications, notices, and downloadable ID card.
  6. Parent Panel — Dashboard for monitoring linked children's attendance, results, assignments, fees, and submitting formal applications and leave requests.
  7. Communication System — A structured, tracked application and complaint system connecting Students, Parents, and Teachers to Admin/Principal with full status history and notifications.
  8. Notification System — Automated in-app notifications triggered by key system events (new assignments, exam schedules, result publishing, fee reminders, application responses, etc.).
  9. ID Card Management — Auto-generated digital ID cards for students and teachers, with QR codes, downloadable and printable from within the system.
  10. Reports & Analytics — Comprehensive reporting for attendance, fees, admissions, results, assignments, and system activity.

The complete functional requirements are defined across 36 modules as documented in the attached EduOS Project Specification Document, which forms an integral part of this Agreement.

The scope of work is further defined in the attached Project Specification Document, which forms an integral part of this Agreement.
