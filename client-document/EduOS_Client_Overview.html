What Is This System?

Think of this as your school or institution's complete digital brain. Instead of using separate tools for attendance, fees, exams, notices, and communication — everything lives in one place, connected, and under your full control.

Core Idea

One System. Everything Connected.

Not just a website with four dashboards. This is a complete digital operating system for your institution — where every activity has a clear owner, a proper process, and a full history.

🏫 What it replaces

  • Paper attendance registers
  • Manual fee receipts and ledgers
  • WhatsApp groups for notices
  • Physical complaint letters
  • Printed result sheets
  • Separate admission paperwork
  • Physical ID card printing process

✨ What you get instead

  • Digital attendance with reports
  • Automated fee tracking and receipts
  • Official notice board system
  • Tracked formal applications
  • Published results with grade cards
  • Online admission workflow
  • Auto-generated digital ID cards

Who Uses It? — The 5 Roles

The system serves five different types of people. Each person only sees what is relevant to them. They all log in through the same door, but are taken to their own private area.

🔑 One Login, Smart Routing: When a user logs in, the system automatically recognises who they are and takes them to the correct panel. A teacher never sees the admin controls. A student never sees another student's data.
🏛️

Admin / Principal

Full Control

Runs and controls the entire institution. Has the highest level of access.

  • Manages all students, teachers and parents
  • Controls fees, exams and results
  • Reviews and approves admissions
  • Manages the public website
  • Views all reports and activity
👨‍🏫

Teacher

Teaching Tools

Manages teaching responsibilities for their assigned classes and subjects only.

  • Takes attendance for assigned classes
  • Creates and marks assignments
  • Enters exam marks
  • Views their class timetable
  • Submits leave applications
🎓

Student

My Education

Accesses their own academic life — assignments, results, fees, notices and more.

  • Views attendance and results
  • Submits assignments online
  • Checks exam schedule
  • Submits leave and fee applications
  • Downloads their digital ID card
👨‍👩‍👧

Parent / Guardian

My Children

Monitors their child's academic life and communicates with the institution formally.

  • Views child's attendance and results
  • Checks fee status and receipts
  • Submits leave requests for child
  • Communicates with teachers and admin
  • Receives important notifications
🌐

Public Visitor

Website Access

Anyone browsing the internet can visit the public website. They can view institution information, browse programs, and submit an admission application. They do not get access to any academic area.

How a Student Joins — Admission Flow

The entire admission process happens inside the system — from the moment a parent fills out an online form, to the moment a student is enrolled and their ID card is ready.

Step-by-Step Admission Process
🌐
Step 1

Parent Visits the Website

A parent goes to the public website and clicks on Admissions. They fill out the online admission form with the student's details.

📬
Step 2

Application Arrives in Admin Panel

The moment the form is submitted, it appears automatically in the Admin's admission inbox. Admin receives a notification.

🔍
Step 3

Admin Reviews the Application

Admin opens the application, reviews all details, and can request additional documents if needed.

✅
Step 4

Admin Approves (or Rejects)

Admin clicks Approve. If rejected, a reason is recorded and the applicant is notified automatically.

👤
Step 5

Student Account is Created

Admin creates the student's account in the system. Login credentials are generated. The parent account is also linked at this stage.

🏫
Step 6

Class and Section Assigned

Admin assigns the student to their class and section. The student now appears in the teacher's attendance list and class records.

🪪
Step 7

ID Card Ready

Once the profile is complete, the system automatically generates the student's official ID card. The student can view, download, or print it from their panel.

How Applications & Complaints Work

Instead of informal WhatsApp messages or physical letters that get lost, the system provides a formal, tracked communication channel. Every request has a unique ID, a status, and a complete history.

Important: This is NOT a chat system. It is a controlled, formal workflow — like submitting a ticket to a helpdesk. Both sides get notifications at every step.

📨 What can be submitted?

  • Leave application
  • Fee-related request or concern
  • Certificate or document request
  • Academic concern or complaint
  • Teacher-related complaint
  • Schedule or timetable request
  • Meeting request
  • General complaint or application

👥 Who communicates with whom?

  • Student → Teacher / Admin / Principal
  • Parent → Teacher / Admin / Principal
  • Teacher → Admin / Principal
  • Admin → Anyone (responds and assigns)

At every step, both the applicant and the reviewer receive an automatic notification. The complete history is saved permanently.

Exams & Results Flow

From creating the exam schedule to publishing final results, everything is controlled and tracked. No result can be published without admin finalisation.

How Exams and Results Work
📅
Admin

Creates Exam Schedule

Admin sets up the exam — name, type (monthly/mid-term/final), date, subject, class, and total marks. Students and teachers are notified automatically.

✍️
Teacher

Enters Marks

After the exam, the teacher logs into their panel and enters each student's marks. They can edit marks until they submit for finalisation.

🔍
Admin

Reviews and Finalises

Admin reviews the entered marks, applies the grading system, and checks everything before publishing.

📢
Published

Results Visible to Students and Parents

Once published, students see their marks, grades, and performance. Parents see the same for their children. Notifications are sent automatically.

Fee Management

The system keeps a complete, transparent record of every fee — what is owed, what has been paid, and what is outstanding. No more manual ledgers or lost receipts.

💰 Fee Types Supported

  • Admission fee
  • Monthly / tuition fee
  • Exam fee
  • Transport fee
  • Other charges
  • Discounts and scholarships

📊 Admin Reports Include

  • Daily and monthly collections
  • Outstanding (unpaid) fees
  • Student-wise fee history
  • Class-wise fee summary
  • Partial payment tracking
  • Digital receipts
Parent visibility: Parents can log in and instantly see what fees are due, what has been paid, and download receipts — without calling the school.

ID Cards

The system automatically generates official ID cards for students and teachers using information already stored. No manual data entry. No separate design software needed.

🎓 Student ID Card Includes

  • Institute logo and name
  • Student photo
  • Student name and ID number
  • Class and section
  • Academic session
  • Parent or guardian name
  • Issue and expiry date
  • QR code for verification

👨‍🏫 Teacher ID Card Includes

  • Institute logo and name
  • Teacher photo
  • Teacher name and ID number
  • Designation and department
  • Assigned subjects
  • Contact information
  • Issue and expiry date
  • QR code for verification
How it works: Once admission is approved and the student's profile (including photo) is complete, the ID card is automatically ready. The student can view, download, and print it from their panel. Admin can also print cards in bulk.
